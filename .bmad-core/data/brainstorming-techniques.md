# Brainstorming Techniques

## Divergent Thinking Techniques

### 1. Classic Brainstorming
**Purpose**: Generate large quantities of ideas without judgment
**Process**: 
- Set clear topic and time limit
- Generate ideas rapidly
- No criticism or evaluation during generation
- Build on others' ideas
**Best For**: Initial idea generation, team creativity

### 2. Brainwriting
**Purpose**: Generate ideas individually before sharing
**Process**:
- Each participant writes ideas silently
- Pass papers to build on others' ideas
- Share and discuss after writing phase
**Best For**: Introverted participants, avoiding groupthink

### 3. Mind Mapping
**Purpose**: Visual exploration of ideas and connections
**Process**:
- Start with central topic
- Branch out with related ideas
- Use colors, images, and keywords
- Connect related concepts
**Best For**: Visual thinkers, exploring relationships

### 4. SCAMPER Technique
**Purpose**: Systematic idea generation using prompts
**Process**:
- **S**ubstitute: What can be substituted?
- **C**ombine: What can be combined?
- **A**dapt: What can be adapted?
- **M**odify: What can be modified?
- **P**ut to other uses: How else can this be used?
- **E**liminate: What can be removed?
- **R**everse: What can be rearranged?
**Best For**: Product development, process improvement

### 5. Six Thinking Hats
**Purpose**: Explore ideas from different perspectives
**Process**:
- **White**: Facts and information
- **Red**: Emotions and feelings
- **Black**: Critical judgment
- **Yellow**: Positive assessment
- **Green**: Creativity and alternatives
- **Blue**: Process control
**Best For**: Comprehensive analysis, team alignment

### 6. Random Word Technique
**Purpose**: Stimulate creative thinking through forced connections
**Process**:
- Select random word from dictionary
- Force connections between word and problem
- Explore analogies and metaphors
- Build ideas from unexpected associations
**Best For**: Breaking mental blocks, creative inspiration

### 7. What If Scenarios
**Purpose**: Explore possibilities through hypothetical situations
**Process**:
- Generate "What if..." questions
- Explore implications and opportunities
- Consider extreme scenarios
- Build solutions for different futures
**Best For**: Strategic planning, risk assessment

### 8. Reverse Brainstorming
**Purpose**: Generate ideas by considering opposites
**Process**:
- Define how to cause the problem
- Identify what would make things worse
- Reverse the negative ideas into solutions
- Find prevention strategies
**Best For**: Problem-solving, identifying risks

## Convergent Thinking Techniques

### 9. Affinity Grouping
**Purpose**: Organize ideas into meaningful categories
**Process**:
- Write each idea on separate note
- Group related ideas together
- Name each group/category
- Identify patterns and themes
**Best For**: Making sense of many ideas

### 10. Dot Voting
**Purpose**: Prioritize ideas democratically
**Process**:
- Post all ideas visibly
- Give each participant dots to vote
- Allow multiple votes per person
- Tally votes to identify priorities
**Best For**: Quick prioritization, group consensus

### 11. Impact/Effort Matrix
**Purpose**: Evaluate ideas based on impact and implementation effort
**Process**:
- Create 2x2 matrix (High/Low Impact vs High/Low Effort)
- Plot each idea on matrix
- Focus on high impact, low effort ideas first
- Plan implementation sequence
**Best For**: Strategic prioritization, resource allocation

### 12. RICE Scoring
**Purpose**: Quantitative prioritization framework
**Process**:
- **R**each: How many people affected?
- **I**mpact: How much impact per person?
- **C**onfidence: How confident in estimates?
- **E**ffort: How much work required?
- Calculate RICE score: (Reach × Impact × Confidence) / Effort
**Best For**: Product development, feature prioritization

## Specialized Techniques

### 13. Role Storming
**Purpose**: Generate ideas from different personas' perspectives
**Process**:
- Assign different roles/personas to participants
- Brainstorm from each persona's viewpoint
- Consider different stakeholder needs
- Combine perspectives for comprehensive solutions
**Best For**: User-centered design, stakeholder analysis

### 14. Storyboarding
**Purpose**: Visualize ideas through narrative sequences
**Process**:
- Create visual story of user journey
- Sketch key scenes and interactions
- Identify pain points and opportunities
- Design solutions within story context
**Best For**: User experience design, process improvement

### 15. Assumption Storming
**Purpose**: Surface and challenge underlying assumptions
**Process**:
- List all assumptions about the problem
- Challenge each assumption's validity
- Generate ideas if assumptions were different
- Find opportunities in assumption gaps
**Best For**: Innovation, paradigm shifts

## Technique Selection Guidelines

### For Problem Definition
- Mind Mapping
- Six Thinking Hats
- Assumption Storming

### For Solution Generation
- Classic Brainstorming
- SCAMPER
- Random Word Technique

### For Innovation
- Reverse Brainstorming
- What If Scenarios
- Role Storming

### For Evaluation
- Impact/Effort Matrix
- RICE Scoring
- Dot Voting

### For Complex Problems
- Six Thinking Hats
- Storyboarding
- Affinity Grouping

## Facilitation Tips

### Energy Management
- Start with warm-up exercises
- Vary techniques to maintain engagement
- Take breaks when energy flags
- Celebrate creative thinking

### Group Dynamics
- Encourage all voices
- Manage dominant personalities
- Create safe space for sharing
- Build on others' ideas

### Output Quality
- Capture everything during generation
- Don't edit during divergent phases
- Use visual displays when possible
- Document process and results
