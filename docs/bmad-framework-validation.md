## Usage Examples

### Activating the Analyst Agent:
```
I want to use the analyst agent from the BMad Method framework
```

### Available Commands:
1. `help` - Show all available commands
2. `create-project-brief` - Generate project requirements documentation
3. `perform-market-research` - Conduct market analysis
4. `create-competitor-analysis` - Analyze competitive landscape
5. `brainstorm {topic}` - Facilitate brainstorming session
6. `research-prompt {topic}` - Generate research prompts
7. `elicit` - Advanced content elicitation
8. `yolo` - Toggle rapid processing mode
9. `doc-out` - Output current document
10. `exit` - Deactivate agent
